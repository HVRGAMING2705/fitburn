🔥 FitBurn — Calorie Burn Predictor

A 2nd-year B.Tech AI/ML project by Vikranth Reddy. A ridge regression model trained on 600 synthetic workouts predicts the calories a workout burns. 5-fold CV: R² = 0.907, MAE = 89.8 kcal vs a 310.6 kcal mean-guess baseline.

How it works: each input is standardised with the training means and standard deviations, then multiplied by the model's learned coefficients. The exact same weights run in this page and in the Python training script (train.py), so the browser result matches the trained model to within 0.01 kcal.

Model: Ridge regression (α = 1.0) on standardised features — age, weight, duration, average heart rate, intensity (MET). Try a sample: 30 yrs, 75 kg, 90 min, 155 bpm, 8.5 MET → about 964 kcal.
